# 商家便利计

一款面向个体商户、小微商家的**纯本地单机版**商品信息管理 APP。所有数据完全存储在手机本地，全程无需联网、无需注册登录，安装即可使用。

## 功能特性

### 商品信息管理
- 新增、编辑、删除商品，长按商品弹出快捷操作菜单
- 商品主图支持**相机拍摄**和**相册选择**两种方式，图片自动压缩存储在 APP 私有目录
- 商品字段：名称（必填）、商品介绍、进价、售价、分类、库存数量、备注
- **自动计算**：利润额 = 售价 - 进价，利润率 = (售价 - 进价) / 进价 × 100%，输入即实时显示

### 商品浏览与检索
- 圆角卡片列表 / 简洁列表两种视图自由切换
- 顶部搜索栏，按商品名称关键词实时搜索
- 支持按价格高低、利润高低、新增时间排序
- 支持按商品分类筛选

### 首页数据概览
- 统计卡片：商品总数量、平均利润率、库存总价值、预估总利润
- 利润排名 Top 10 商品榜单

### 数据备份与导出
- 一键备份全部数据为本地备份文件
- 从本地备份文件导入恢复商品信息
- 商品列表导出为 CSV 格式，可保存或分享

## 设计风格

- **圆润柔和**：所有页面、卡片、按钮、输入框均采用 16-24dp 大圆角设计，搭配柔和投影
- **护眼配色**：浅米白背景 + 暖红色强调色 + 深灰文字，低对比度适合长时间使用
- **流畅交互**：按钮点击缩放反馈、输入框聚焦描边过渡、列表滑动动画
- **深色模式**：支持浅色/深色主题切换

## 权限说明

本 APP 仅申请以下权限，**不申请任何网络权限**：

| 权限 | 用途 |
|------|------|
| CAMERA | 拍摄商品照片 |

所有商品数据和图片均存储在 APP 私有目录（`/data/data/com.shopmanager.app/`），卸载 APP 时数据会一并清除，请定期使用备份功能。

## 构建方式

### 环境要求
- JDK 17
- Android SDK (compileSdk 34, build-tools 34.0.0)
- Gradle 8.5

### 编译步骤
```bash
# 克隆项目
git clone <repo-url>
cd ShopManager

# 配置 local.properties（指向你的 Android SDK 路径）
echo "sdk.dir=/path/to/android-sdk" > local.properties

# 编译 Debug APK
./gradlew assembleDebug

# 产物位置
# app/build/outputs/apk/debug/app-debug.apk
```

### 项目结构
```
app/src/main/
├── java/com/shopmanager/app/
│   ├── App.kt                    # 应用入口，全局异常处理
│   ├── MainActivity.kt           # 主 Activity，底部导航
│   ├── data/                     # Room 数据层（实体/DAO/数据库/仓库）
│   ├── ui/
│   │   ├── home/                 # 首页（数据概览 + 利润榜单）
│   │   ├── products/             # 商品列表（搜索/排序/筛选/视图切换）
│   │   ├── editor/               # 商品编辑（新增/编辑/图片上传）
│   │   ├── data/                 # 数据页（备份/恢复/导出）
│   │   └── common/               # 通用（图片查看器）
│   ├── adapter/                  # RecyclerView 适配器
│   └── util/                     # 工具类（图片/备份/CSV/主题/数字）
└── res/
    ├── layout/                   # 12 个布局文件
    ├── drawable/                 # 形状背景 + 矢量图标
    ├── values/                   # 颜色/字符串/主题/尺寸
    ├── values-night/             # 深色模式资源
    ├── mipmap-*/                 # 自适应图标（记事本 + 购物车）
    └── xml/                      # FileProvider 配置
```

## 应用图标

图标主体为一本浅米色圆角记事本，带有装订线和页角翻折细节；封面偏右下位置放置一个圆润的暖红色购物车图标，直观体现"记账记录 + 商品管理"的产品属性。严格遵循安卓自适应图标规范，适配圆形、方形、圆角方形等各种桌面蒙版。

## 已知问题

- **相机首次启动**：首次使用相机拍照时，授予相机权限后可能出现一次崩溃，重新点击相机即可正常使用。后续使用不会再出现此问题。
